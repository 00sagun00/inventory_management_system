Inventory Management System

A Python-based offline Inventory Management System built using Python, Tkinter, and SQLite3 to help small businesses manage products, track stock, and monitor inventory.

Key Features

Dashboard with total products, stock quantity, and inventory value.
Add, update, delete, and view products (CRUD).
Search products by name, category, and supplier.
Category-wise product filtering.
Automatic stock status: In Stock, Low Stock, Out of Stock.
Inventory reports and statistics.
SQLite database for offline data storage.
Input validation and error handling.
User-friendly Tkinter GUI.
